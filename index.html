013.6 KOL — 콘텐츠 5종 구체화

버전 3.6은 "기존 팬덤 결속 + 라이트 유저 유입"을 동시에 노리는 구성. 성우 토크쇼(팬덤 심화) → 영입회(신규 유입) → 애니메이션(대중 확산) → 델크쇼(밈 확산)로 타깃이 점점 넓어지는 퍼널 구조로 설계했습니다.

3.6-1

성우 토크쇼 — 「목소리의 뒷면」

캐릭터를 연기한 성우가 직접 나와 녹음 비하인드를 푸는, 팬덤 만족도 최상위 콘텐츠

기획 의도
  • 2주년 페스티벌에서 이미 검증된 포맷 — 성우 토크쇼 하이라이트 클립이 개인 채널에서 3.8만 조회 기록. 반응 데이터가 확보된 상태
  • 3.6 신규/메인 공명자 성우를 섭외해 "이 캐릭터를 어떻게 만들었나"를 공개
  • 게임 내 정보가 아닌 제작 비하인드라 스포일러 리스크가 낮고 버전 무관하게 소구
  • 성우 팬덤 → 게임 유입, 게임 팬덤 → 성우 팬덤의 교차 유입 발생
  • 클립 단위 확산성이 매우 높음 (명대사 재연, 성대모사 등)
포맷온라인 라이브 1회 (약 90~120분) + 하이라이트 VOD 1건
출연성우 2~3인 + 진행 MC 1인 (명조 이해도 높은 크리에이터)
송출명조 공식 채널 (치지직) 메인 / MC 개인 채널 동시 송출
타깃기존 유저 · 성우 팬덤 · 스토리 중심 라이트 유저
코너 구성
  • 오프닝 — 목소리 블라인드 퀴즈 성우가 캐릭터 목소리로 인사 → 시청자가 누구인지 맞히며 시작. 초반 채팅 참여율 확보
  • 1부 — 캐릭터 해석 토크 "이 캐릭터를 어떻게 이해했는가", 감정선 설계, 캐릭터에 대한 성우 본인의 애정 포인트
  • 2부 — 녹음 부스 비하인드 NG 에피소드, 가장 힘들었던 대사, 디렉터 요청 비화. 가능하면 실제 녹음 음원 미공개 테이크 공개
  • 3부 — 명대사 라이브 재연 시청자 신청 대사를 현장에서 즉석 연기. 클립 확산의 핵심 코너
  • 4부 — 실시간 Q&A 사전 접수 + 실시간 채팅 질문. 답변자에게 굿즈/사인 증정
  • 엔딩 — 3.7 예고 멘트 다음 버전 티저 멘트를 성우 목소리로 녹음해 마무리 → 차기 버전 기대감 연결
확인 필요 — 성우 섭외는 리드타임이 가장 길다. 소속사 스케줄 · 초상권/음원 사용 범위 · 재연 가능 대사 범위를 최소 6~8주 전 확정 필요. 미공개 테이크 공개 여부는 개발사(쿠로) 승인 필수.
3.6-2

영입회 — 「명조 영업 브리핑」

명조를 안 하는 크리에이터/시청자를 대상으로 한, 웃기고 뜨거운 ‘게임 영업’ 콘텐츠

기획 의도
  • 기존 유저 대상 콘텐츠와 달리 명조를 모르는 사람을 정조준하는 유일한 축
  • 레퍼런스처럼 "웃기려고 시작했는데 진심이 되는" 구조가 전환율이 가장 높음
  • 진입장벽(전투 어렵다, 스토리 길다)에 대한 선제적 방어 논리 제공
  • 영업 당하는 게스트의 리액션 자체가 콘텐츠 — 게임 실플레이 없이도 성립
포맷온라인 라이브 1회 (약 120분), PPT 발표 배틀 형식
출연영업자(명조 헤비 유저) 2~3인 + 피영업자(비유저·복귀 유저) 2~3인
캐스팅영업자 — 명조 이해도 최상위 / 피영업자 — 타 게임 팬덤 보유 크리에이터
핵심 KPI방송 중/후 신규 가입 쿠폰 코드 사용률로 전환 측정
코너 구성
  • 1라운드 — 3분 PPT 영업전 영업자가 직접 만든 PPT로 "명조를 해야 하는 이유" 발표. 진지 + 드립 혼합이 핵심
  • 2라운드 — 편견 격파 "전투 어렵지 않아?" "지금 시작하면 늦지 않아?" 등 실제 커뮤니티 반응을 반박. 신규 유저 온보딩 정보를 자연스럽게 노출하는 구간
  • 3라운드 — 현장 체험 피영업자가 즉석에서 계정 생성 → 튜토리얼~첫 전투 플레이. 실제 첫인상 리액션 확보
  • 4라운드 — 스토리 한 장면 감상 스포일러 없는 명장면 1개를 함께 시청. 레퍼런스의 "감동" 지점을 의도적으로 설계
  • 최종 — 영입 판정 & 계약서 사인 피영업자가 "영입 수락/거절" 선언. 수락 시 대형 영입 계약서 퍼포먼스 → 짤 생성
확산 설계 — 피영업자의 “계약” 이후 1~2주 뒤 후속 플레이 방송을 세트로 계약할 것. 영입회 단발로 끝나면 전환이 휘발된다. "정말 하고 있는지" 확인하는 애프터 체크 방송이 실제 리텐션을 만든다.
3.6-3

애니메이션 — 「청초의 제자」 (가제)

픽셀 멤버 5인이 3.6 신규 공명자 청초의 제자가 되기 위해 고군분투하는 오리지널 2D 애니메이션 제작. 기존 영상 재활용이 아닌 신규 IP 콘텐츠 자체 생산

기획 의도
  • 픽셀은 이미 「@애니메이션」 시리즈를 자체 운영 중 — 「새로운 일본인 친구」 「스카이다이빙」 등. 포맷·제작 파이프라인이 검증된 상태
  • 멤버 캐릭터화가 이미 정착되어 시청자가 캐릭터를 인지한 상태에서 시작
  • 게임 플레이 영상이 아니므로 미설치자도 진입장벽 없이 소비 가능
  • 청초의 심검(이기어검) 검술이라는 시각적 강점을 애니메이션으로 극대화
  • 다양한 스트리머의 IP를 활용하므로 각 멤버의 팬층이 겹쳐 유입 — 여러 팬덤이 해당 영상을 볼 확률이 높아져 데이터적으로 좋은 성과 기대 가능
  • 업데이트 당일 업로드를 진행하여, 트래픽이 집중되는 당일에 높은 유튜브 수치도 기대할 수 있음
출연픽셀 멤버 5인 — 남봉 · 임나은 · 연비니 · 금사향 · 설백
소재3.6 신규 공명자 청초 (심검 사용 검술 캐릭터)
줄거리픽셀 멤버들이 청초의 제자가 되기 위해 각자의 방식으로 노력하는 과정
화풍2~3등신 치비 + 굵은 라인아트 + 플랫 컬러 (픽셀 기존 애니 시리즈 톤 유지)
분량3~5분 1편 (기존 「@애니메이션」 시리즈가 3분 내외)
송출픽셀 채널 메인 업로드 + 명조 공식 채널 리포스트
구성안 — 5인 5색 “제자 지원” 구조
  • 도입 — 청초 등장 청초가 심검을 다루는 압도적인 장면 목격 → 픽셀 멤버 5인이 동시에 “제자로 삼아주세요” 선언. 명조 세계관 진입
  • 전개 — 멤버별 어필 (핵심 코미디 구간) 5인이 각자 다른 방식으로 제자 지원. 멤버별 개그 캐릭터성을 그대로 활용해 각 팬덤이 자기 최애 구간을 클립으로 잘라 확산하는 구조
  • 위기 — 전원 탈락 위기 제각각 헛발질 → 청초의 냉담한 반응. 명조 세계관의 실제 설정 (심검 수련 난이도)을 코미디 소재로 소화
  • 결말 — 반전 예상 밖 멤버가 인정받거나, 5인이 협력해 통과. 3.6 버전 플레이 유도 멘트로 마무리
멤버별 어필 방식 (안) — 5인 5색
멤버제자 지원 방식 (안)기대 포인트
남봉정공법 — 실제로 검술을 파고들어 가장 진지하게 수련 띵킹 띵티어 캐스팅과 연결되는 “실력파” 포지션
임나은아부·아첨형 — 청초 찬양으로 환심 사기 시도 대사량 많은 코미디 구간, 클립 확산 최적
연비니모방형 — 청초 말투·복장·자세를 그대로 따라함 코스프레 · 2차 창작 유도
금사향정면 돌파 — 대련 신청 후 순식간에 패배 심검 액션 작화를 보여주는 구간
설백의외의 재능 — 무심하게 따라했는데 성공 결말 반전 담당 — 마지막 한 방

※ 멤버별 실제 캐릭터성은 픽셀 측과 협의 후 확정. 위는 배치 구조 예시안입니다.

확인 필요 — 3.5 / 3.6 버전 귀속
요청 시 “3.5-3”으로 언급되었으나 청초는 3.6 신규 공명자입니다 (3.5 스토리 컷씬에 선행 등장). 본 문서는 3.6-3으로 배치했으니 3.5 항목이 맞다면 알려주시면 이동하겠습니다.
제작 리드타임 — 최우선 발주 항목
3~5분 2D 애니메이션은 기획 → 콘티 → 작화 → 편집에 통상 6~10주 소요됩니다. 버전 업데이트 D-7 공개를 목표로 한다면 지금 시점에 발주가 시작되어야 합니다. 청초 공식 3D 모델링·설정화의 사전 제공 여부도 함께 확인이 필요합니다.
3.6-4

델크쇼 — 「명조편 시즌2」

기존 인기 토크쇼 포맷에 명조를 얹는 방식. 이미 검증된 재미 — 리스크가 가장 낮은 카드

기획 의도
  • 이미 명조편을 진행한 실적이 있어 반응 데이터가 확보된 상태 — 예측 가능성 최고
  • 토크쇼 고정 시청층에게 정기적으로 명조가 노출되는 구조 (브랜드 잔상 효과)
  • 게임 플레이 실력과 무관해 출연 크리에이터 폭이 가장 넓음
  • 드립 · 밈 생산량이 많아 커뮤니티 확산 효율이 높음
포맷토크쇼 1회 (약 120~150분) + 클립 3~5건
출연호스트 1인 + 게스트 3~4인 (명조 크리에이터 + 외부 게스트 혼합)
차별점1회차 대비 3.6 신규 콘텐츠 기반 코너를 신설해 반복감 제거
타깃토크쇼 고정 시청층 · 라이트 유저 · 커뮤니티 유저
시즌2 신설 코너 제안
  • 명조 인간관계도 그리기 게스트가 기억나는 대로 캐릭터 관계도를 그림 → 정답과 비교. 오답이 곧 재미
  • 내 최애 변호하기 각자 최애 공명자를 데려와 변호. 다른 게스트가 반박 → 팬덤 화력 유도
  • 3.6 신규 콘텐츠 초면 체험 신규 콘텐츠를 방송 중 처음 접하고 리액션. 버전 홍보의 실질 축
  • 명조 아무말 대잔치 (밈 코너) 커뮤니티 밈/짤을 보고 해설. 클립 확산량이 가장 큰 구간
  • 엔딩 — 시청자 사연 & 굿즈 추첨 사연 채택자에게 3.6 콜라보 굿즈 증정 → 참여 동기 부여
제안 — 델크쇼는 영입회 직후 배치하는 것이 효율적이다. 영입회로 유입된 신규 유저가 "이 게임 커뮤니티 분위기가 이렇구나"를 체감하는 정착 콘텐츠 역할을 하기 때문.
3.6-5

뜨뜨뜨뜨 — 「전역 복귀」 타이밍 선점

구독자 146만 · 영상 1,970개의 대형 게임 채널. 2026년 7월 전역과 동시에 채널 복귀 — 복귀 직후 주목도가 최고조인 시점에 과업을 배치해 평시 대비 높은 조회 지표를 확보하는 안

기획 의도
  • 입대 영상이 150만 조회 — 「뜨뜨뜨뜨 군대 갑니다」(17:04)가 1년간 150만 회. 부재 기간에도 팬덤이 이탈하지 않고 복귀를 기다린 채널
  • 전역 = 구독자 알림이 일제히 켜지는 이벤트. 복귀 초기 영상은 평시 대비 시청 유입이 집중되는 구간
  • 1년 공백 = "그동안 뭐가 나왔나" 서사가 자연스럽게 성립 — 신작·신규 버전 소개에 명분이 붙는 드문 타이밍
  • 기존 주력이 LoL·바람의나라 등 명조 미노출 시청층 — 기존 KOL 풀과 겹치지 않는 신규 유입 경로

  • 2단계 — 전투 시스템 집중 액션 게임 숙련도가 높은 채널 특성상 회피·패링 등 전투 깊이를 보여주는 구간이 가장 설득력 있음
  • 3단계 — 라이브 연계 편집 영상 공개 후 라이브로 시청자와 함께 플레이. 실시간 질의응답으로 진입 장벽 해소

023.7 KOL — 콘텐츠 4종 구체화

3.7은 "제작 과정 공개 + 크리에이터 심화 협업"이 축. 드로잉(제작 감성) → 본사 방문(개발사 신뢰) → 띵킹2(경쟁 화력)로, 버전 초반·중반·후반을 각각 담당하는 3단 구성입니다.

3.7-1

띵조를 부탁해 — 드로잉 키친

「냉장고를 부탁해」 패러디 — 랜덤 재료(룰렛)로 즉석 캐릭터 일러스트 대결

기획 의도

  • 시청자가 ‘히든 재료’로 직접 개입하므로 참여형 설계가 자연스러움
  • 결과물(일러스트)이 그대로 굿즈·SNS 자산이 됨 — 콘텐츠 1개로 산출물 2개
  • 전투 실력 무관 — 라이트 유저·비유저도 편하게 시청 가능
콘텐츠명명조 드로잉 키친 (냉장고를 부탁해 패러디)

    예) 치샤 + 친구와 싸운 뒤 + 기쁜 + 물구나무 서기
  • 드로잉 대결 (10분) 일러스트 작가 2인이 동시 작업. MC가 타이머 노출 및 중계 진행
  • 히든 재료 투입 (5~7분 시점) 시청자가 채팅/구글폼으로 키워드 제출 → 랜덤 추첨 → 작가가 그림에 즉석 반영. 가장 큰 웃음 포인트이자 참여 유도 구간
  • 평가 & 투표 MC 평가 후 시청자·크리에이터 투표로 우승작 선정
  • 결과물 활용 완성 일러스트를 굿즈(아크릴/엽서)로 제작 → 롯데시네마 오프라인 증정품으로 연계
연계 포인트 — 온라인 드로잉 키친에서 나온 우승작을 롯데시네마 3.7 현장 굿즈로 제작하면, 온라인 참여자가 오프라인 행사에 오는 동기가 생긴다. "내가 낸 히든 재료가 들어간 그림이 굿즈가 됐다"는 서사가 강력함.

A안 — 「명조 시네마 아레나」 (메인 추천)

기획 의도
  • 극장의 가장 큰 자산은 거대 스크린 + 사운드 — 이걸 게임 화면으로 쓰는 게 핵심
  • 집에서 하던 명조 전투를 영화관 스케일로 체험하는 경험 자체가 티켓 파워

  • 띵킹2(온라인 대회)와 오프라인-온라인 세계관 연결 가능

    관객은 스마트폰으로 실시간 전략 투표(어떤 공명자를 쓸지, 어떤 스킬을 쓸지) → 투표 결과가 플레이어에게 전달되어 실제 조작에 반영.
    관객 전원이 하나의 파티가 되는 구조
  • ROUND 2 — 명조 스크린 퀴즈 배틀 (20분) 좌석 구역별(A/B/C 블록) 팀 대항. 스크린에 문제 노출 → 스마트폰 응답 → 실시간 순위 스크린 표시. 구역 대결 구조라 현장 함성 유발
  • ROUND 3 — 성우 라이브 더빙쇼 (20분) 스크린에 음성을 제거한 게임 시네마틱 재생 → 성우가 현장에서 라이브 더빙.
